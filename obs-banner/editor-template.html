First time in OBS?
  1. Save the banner in a permanent folder.
  2. Sources → + → Browser → Local file.
  3. Select your saved HTML file.
  4. Set the width and height shown above.
  5. Position it, then lock the source.
  6. Hide the old scrolling text.
Runs entirely on your computer. No account, subscription or internet connection needed. Editor changes only reach OBS when you save the banner file and refresh the source.
