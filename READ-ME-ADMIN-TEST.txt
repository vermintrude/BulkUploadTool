STANDARD AI RESUME
Completed comics are skipped on retry. On a timeout the progress explicitly
says STOPPED, how many completed and how many remain. Existing AI results and
manually corrected fields for completed comics are kept. Failed requests may
still be chargeable and may need retry; this cannot recover an unseen response.
There is no automatic billable retry. Model, prompts, two-pass verification,
90-second timeout and output transformation are unchanged.

SAVE REVIEW BACKUP downloads the current review as ComicRox-AI-Recovery.json.
Keep it locally/private. RESTORE SAVED REVIEW restores the latest local browser
checkpoint explicitly, or IMPORT REVIEW BACKUP loads a downloaded backup.
Restoring never happens automatically and is blocked during AI processing.
Photo files must remain at their original paths. The backup stores review and
photo references, not photograph contents. Building a new review replaces the
latest local checkpoint; download backups if you need to retain older reviews.
New browser key: comicrox_standard_ai_checkpoint_v1. Existing keys unchanged.
