ComicRox — TikTok Sync

API Usage / Shopify Actions · Return to listing tool

Shopify is the master. This separate tool reads local exports and creates local files. It does not connect to TikTok, change your listings, publish products or synchronise sales automatically.

1. Load your current exports

Export all Shopify products as CSV. Export TikTok Live, Failed, Deactivated and Draft separately through Bulk actions → Edit products → Select products → choose status → Select filtered → All information → Generate template. Include stock quantities. If a status is empty, record that below. Keep Failed listings in the comparison even if the workbook incorrectly labels them Live.

No Shopify export loaded.

Select the source status before adding files. You can add multiple workbooks or a ZIP. Files from different days may disagree; conflicting product IDs block generation until you remove the stale source.

Exports are snapshots. Refresh them after sales or catalogue changes. Incomplete exports can hide existing listings and create duplicates.

2. Confirm packing and import template

Weights must include the comic and its shipping packaging. Dimensions are centimetres; weights are grams. Singles start with your supplied 145 g, 33 × 21 × 0.5 cm. These are editable declarations, not independently measured values. Stock quantity means copies for sale, not comics in one parcel.

3. Review the results

Only active, published, positive-stock Shopify variants can be added. Exact title matches and previously confirmed ID mappings are used. A reused SKU alone is never proof of identity. Possible matches are held for review. Removal recommendations never change TikTok automatically.

4. Create and upload additions only

After reviewing matches and confirming all four export statuses, generate a create workbook containing only ready additions. Keep the existing catalogue. Upload through TikTok → Bulk actions → Upload in bulk. Check TikTok's validation before publishing, especially fractional thickness such as 0.5 cm.

Blank/reused Shopify seller SKUs receive stable unique TikTok SKUs. The mapping is included in the review workbook and saved separately in this browser. Shopify SKUs are not changed. Do not upload the review workbook.

5. Record the import result before retrying

A downloaded workbook is not proof of upload. After TikTok processes it, paste the generated seller SKUs that succeeded (one per line) and record them. Pending rows are withheld on later runs. To retry, enter only failed SKUs and explicitly release those rows after checking TikTok. If no rows were uploaded, use the same release action after confirming that fact.



Backups preserve identity decisions, seller-SKU mappings, packing overrides and import history. Stored only under this tool's own browser key. Keep a backup before moving browsers or clearing site data. Source exports are not retained in browser storage.
